# Project Context
This is a REST API for inventory management built with Node.js, TypeScript, and Express.
It handles product tracking, stock monitoring, supplier management, and reporting for a warehouse operation.

## Documentation Scope
The project includes:
- API reference documentation (docs/api-reference.md)
- Architecture overview (docs/architecture.md)
- Getting started guide (docs/getting-started.md)
- SQL schema and query documentation (sql/)
- Workshop exercise guides (exercises/)

## When Helping Me
- Explain code behavior in plain language suitable for end-user documentation
- Focus on what a feature does, not how it's implemented internally
- When I reference a code file, extract the public-facing behavior and document it
- Suggest diagrams (sequence, flowchart) when a concept is hard to explain in text
- Identify missing documentation by comparing code to existing docs
- Link related docs using relative file paths

## Documentation Standards
- Use second person ("you") not third person
- Write at a Grade 8 reading level using the Hemingway test
- Follow the Microsoft Writing Style Guide for voice and tone
- Every concept should include at least one code example
- Include "Prerequisites" before any procedure
- Include a "Troubleshooting" section for setup/install guides
- Structure: Overview → Prerequisites → Steps → Verification → Troubleshooting
